# TikTok の発信計画(2026-11-18 〜 2027-01-07)

*作成: 2026-10-30 / 書き直し: 2026-11-15(説明の軸・炭の見た目・目標・1.0.3 の中身に合わせた) / 確度: **【暫定】**(本人が読み直して決める。仕様の判断ではないので spec.md には書かない)*

**目標(plan §10):** 2週間使い続ける人を30人。友人には頼まず、発信を見た人にダウンロードしてもらう。

TikTok の仕事は3つ。

1. 「KATSU 習慣」/ `KATSU habit` と検索させて、ストアのページまで来てもらう
2. 入れた人に、**小さく始める**ことを先に伝えておく(大きく始めた人ほど2週間もたない)
3. コメントで、使った人の声を聞く(plan §10「反応を見るまで機能を足さない」の材料)

1.0.3 は 2026-11-14 に公開済み。**この計画の動画は、全部いまのアプリで撮れる。**

## 0. 守ること(台本を書く前に毎回見る)

### 説明の軸

**「忘れている自分を、いまに戻す一声。」/ `The voice that brings you back.`**(spec §1)

- 敵は弱い自分ではなく、うっかり流れていく毎日。習慣は意志の力ではなく、同じ時刻・小さな行動・繰り返しで作る
- 「弱い自分に打ち勝つ」「叱咤激励」「自分を追い込む」とは言わない(spec §9-14)
- ただし言葉の厳しさは弱めない。**厳しく書くのは本人の自由**で、アプリが励ますわけでも叱るわけでもない(spec §9-7)
- 「卒業させる習慣アプリ」は今も本当のこと(spec §1 思想)。ただ、1本目の掴みには使わない。卒業の回(連載 D)で見せる

### 決まり

| 決まり | 出どころ | 動画での具体例 |
|---|---|---|
| 感嘆符を使わない。煽らない。罪悪感をあおらない | CLAUDE.md / spec §1 | `Don't break your streak!` は書かない |
| やらなかった日を「失敗」と呼ばない。数え直しを「リセット」「失敗」と言わない | CLAUDE.md | 「休みの日」「数え直し」/ `rest day` `the count starts over` |
| 卒業まわりで「連続」「in a row」「streak」を使わない | CLAUDE.md 決定済みの細部 | `66 days. All done.` /「66日、やり切りました。」 |
| 研究は「ある研究で、中央値66日」。`research found` `science says` と言わない。全員が66日で身につくと言わない | asc-listing「研究に触れるときの決まり」 | `In one study, the median was 66 days.` /「ある研究では中央値で66日」 |
| 「直近7日で休み2回まで」はアプリの決まり。研究の数字と言わない | 同上 | `KATSU's rule, not a study's.` |
| 「サボった」「三日坊主」を画面の文字に出さない | asc-listing | 「やらなかった日」「時間を過ぎた」 |
| アプリが言葉を書く、と読める見せ方をしない。言葉の例はアプリに無い | spec §1 / plan §8 | 例文は**開発者本人が自分に書いた言葉**として出す |
| 他人の言葉をロック画面・共有カードに勝手に載せない | plan §7-4 | 撮影用端末の言葉は本人のもの |
| 言葉は端末から出ない。アプリから投稿・送信する機能は無い | spec §4 | 「自分で書いて、自分で投稿して」 |
| 「喝」は眠っている者を叩き起こす一喝。罵倒ではない。人格ではなく行動を叱る | spec §1 / §2 安全設計 | ×「お前はクズだ」 ○「起きるって決めたのはお前だろ」 |
| 撮影に入れないもの | — | 他アプリの通知、実名・メール、テスト用の表示 |

### 文章の書き方(spec §9-13 と同じ。AI の癖を避ける)

- 「〜ではなく、〜」「〜じゃない。〜だ。」の対比で盛り上げない
- 決め台詞で締めない(「それでいい。」「一日ずつ。」「約束の相手は〜」)
- 事実を短く書く。何が起きるか、何をすればいいかだけ
- 英語は短縮形を使う普通の話し言葉
- 最後に余計な励ましを足さない

### 見た目(spec §1 見た目の方向)

- **地は炭 `#2B2A28`、字は生成り `#F0EDE5`。**真っ黒・真っ白は使わない
- 字幕は**太いゴシック**(ヒラギノ角ゴ W8)。明朝は使わない
- 色は2色だけ。赤・黄色の強調、絵文字、紙吹雪、効果音は使わない(アプリと同じ)
- この見た目は `tools/video/cut.py` が自動で付ける(§3)
- ⚠ 9月の素材(`~/katsu-demo/clip*.mov`)は紺と明朝の 1.0.1。**画面が今と違うので使わない。**全部撮り直す

## 2. アカウント・投稿先・撮影

### アカウント 【未確定・本人が決める】

**提案:** 新しいアカウントを作る(個人のアカウントは使わない)。**最初は日本語のアカウント1つ**で始め、英語は後から足す。

- 理由: 週に数時間で回すため。TikTok は投稿した人のいる地域にまず見せる傾向があり、日本から英語で出しても、はじめは日本の人に見られやすい 【未確認: 通説。TikTok は公式に言っていない】
- **同じ動画を YouTube Shorts と Instagram リールにも上げる。**ファイルは同じなので手間はほとんど増えない。英語の動画は、国を越えて届きやすいと言われる Shorts を中心に試す 【未確認: 通説】
- 英語の TikTok アカウントを作るなら、最初の5本で分析の「視聴者の国」を見て、英語圏に届いているか確かめる。届いていなければ英語は Shorts だけにする
- 地域をごまかす方法(VPN など)は使わない
- 名前の例: JA `@katsu_jp` / EN `@katsu.app`(空いているものを取る)
- プロフィール JA: `忘れている自分を、いまに戻す一声。決めた時刻を過ぎたら、自分で書いた言葉が届く。iPhone。`
- プロフィール EN: `The voice that brings you back. Your own words, when the time you set passes. iPhone.`

**リンク:** TikTok のプロフィールにリンクを置けるかは条件がある(フォロワー数やアカウントの種類) 【未確認: 最新の条件を TikTok で確かめる】。置けない間は、CTA を「App Store で検索」にする。置けるようになったらキャンペーンリンク(§6)を貼る。

### 検索させる言葉(CTA)

- JA: 「App Store で『KATSU 習慣』」(名前が `KATSU 習慣化・ルーティン ~自分に喝~`)
- EN: `Search "KATSU habit" on the App Store`(名前が `KATSU: Habit Tracker & Routine`)
- ⚠ 「KATSU」だけだと料理アプリや同名のアプリが出る。必ず「習慣」/ `habit` を付ける

### 撮影

| 何を | どこで | どう撮る |
|---|---|---|
| アプリの画面(Today・設定・言葉・節目・卒業) | シミュレーター | `tools/video/record.sh`(§3)。状態と言語を指定して起動し、9:41 にそろえて撮る。操作は Mac のマウスで |
| **ロック画面の通知・通知のボタン・ウィジェット・アイコン長押し** | **実機** | 画面収録。壁紙は無地、集中モードで他アプリの通知を止める |
| 手元・部屋(布団から出る足、机など) | 実機のカメラ | 縦で撮る。顔は出さなくてよい |
| 声 | 実機のボイスメモ | 静かな部屋で。無音でも成り立つ作りにする |

- 撮影用端末の言葉は**本人が本当に自分に書いた言葉**にする(作った台詞にしない)
- ⚠ 振動は映らない。チェックの手応えは、日数の数字が動く場面で見せる
- **まとめ撮り:** 週に1回(日曜1〜2時間)、1週間ぶんの素材を撮る。毎日の作業は台本を書いて頼むことと、投稿だけにする(§9)

## 3. 動画の作り方(Claude Code でやる)

道具は `tools/video/`。素材と仕上がりは**リポジトリの外の `~/katsu-video/`** に置く(リポジトリは公開なので、本人の言葉が写った素材を入れない)。

```
~/katsu-video/
  raw/      撮った素材(実機から AirDrop / iCloud Drive で入れる、シミュレーターの録画)
  cuts/     台本(D01-ja.cut など)
  out/      仕上がり(D01-ja.mp4)
```

**1. シミュレーターで撮る**

```sh
bash tools/sim/build.sh     # 撮影用の版を入れる(初回のみ・アプリを直したとき)
bash tools/video/record.sh ~/katsu-video/raw/today-ja.mov --seed progress --lang ja          # Enter で止める
bash tools/video/record.sh ~/katsu-video/raw/words-en.mov --screen onboarding:words --lang en -t 20
```

状態(`--seed`)・画面(`--screen`)・ルーティンの組(`--theme`)の名前は `docs/HANDOFF.md`「撮影用の状態と画面」。

**2. 台本を書いて組み立てる**

```
# ~/katsu-video/cuts/D01-ja.cut
card  2.0  7時5分。\nまだ布団の中。
clip  ../raw/lock-0705.mov  from=3 to=11
card  2.5  App Store で\n『KATSU 習慣』
text  2.0  10.0  bottom  これは自分で書いた。\n時刻を過ぎたら、KATSU が届ける。
```

```sh
python3 tools/video/cut.py ~/katsu-video/cuts/D01-ja.cut -o ~/katsu-video/out/D01-ja.mp4 --preview
```

- 1080×1920・30fps。縦横比が違う素材は炭の地に収まる(シミュレーターの画面は左右に炭の帯が付く。アプリの地と同じ色なので境目は見えない)
- `text` の秒は動画の頭から。実行すると各場面の開始秒が出るので、それを見て合わせる
- 日本語は `\n` で自分で区切る(自動の折り返しだと語の途中で切れる)
- 字幕は TikTok の右のボタンと下の説明文にかからない範囲に置く。`--preview` の1枚で確かめる
- 書き方の全部は `cut.py` の先頭のコメント

**3. スマホから頼む**

Mac で Claude Code を開いて `/remote-control` を打っておくと、スマホの Claude アプリから同じセッションに入れる。Mac は電源につなぎ、スリープさせない。

- 撮る(実機)→ AirDrop か iCloud Drive で `~/katsu-video/raw/` へ → スマホから「D05 の日本語版を作って」→ 仕上がりを iCloud Drive で受け取って投稿
- クラウドの Claude Code(Mac なし)では、Mac の中の素材・シミュレーター・ヒラギノが使えない。台本の文章を考えるだけならできる(書体は `KATSU_FONT` で差し替えられる)

## 8. TikTok の決まりで守ること

- [ ] **誤解を招く言い方をしない:** 「66日で必ず身につく」「科学的に証明」と言わない(§0)。ダウンロード数・レビューを盛らない。数字は ASC の画面そのまま

- [ ] **音楽:** 自分の声か、TikTok の**商用利用可の音源**(Commercial Music Library)だけ。流行りの曲は使わない 【未確認: 個人アカウントでの扱い】

- [ ] **AI で作った映像・声は使わない**(使うならラベルを付ける)。`cut.py` は編集だけで、映像も声も作らない
- [ ] **他人を映さない・他人の言葉を勝手に使わない:** 紹介するのは公開で書かれたもので、名前を消してから
- [ ] **自傷にかかわる内容を出さない:** 例文にも、紹介にも。来たら findahelpline.com(§5)
- [ ] **年齢:** 未成年が見ても問題ない言葉にする
- [ ] **Apple の表記:** 「App Store」「iPhone」は正しく書く。バッジを使うなら Apple の決まりに従う 【未確認: 動画内での扱い】
