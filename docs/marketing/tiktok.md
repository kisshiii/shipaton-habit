## 1. 方針

### 基準の1行(全部の投稿をこれで通す)

> **見た人が、うっかり流れていく自分の毎日を思い出すか。**

伸びそうでも、これに当てはまらないものは出さない。アカウントの客層がずれると、後の投稿が習慣に興味のない人に配られる(通説【未確認】)。

### 見てほしい人(仮)

20〜30代。朝や夜に「やろうと決めたこと」がある。意志が弱いとは思っていないが、気づくと時間が過ぎている。iPhone を使っている。

### 説明の軸

「忘れている自分を、いまに戻す一声。」/ `The voice that brings you back.`(spec §1)。「弱い自分に打ち勝つ」「叱咤激励」「自分を追い込む」とは言わない(spec §9-14)。言葉の厳しさは本人の自由(spec §9-7)。

### 決めたこと(2026-11-15)

| 項目 | 方針 | 理由 |
|---|---|---|
| 手本 | Stronger Mobile(`@strongermobile`)の型だけ | 本人が見て判断。Dumbphone(`@dumbphoneapp`)は「dumbphone」という考え方の知名度で見られているだけで、中身は面白くない |
| 形式 | **2枚のスライド+音楽**(TikTok の写真モード)が中心。動画は、動きに意味がある時だけ | 作るのが安く、本数を出して当たりを探せる |
| 1枚目 | 写真(または炭の地)に、**ひとり言の短い文**。アプリは出さない | 実写と語りかけで広告に見えない。相手を責める形(「まだ寝てるの?」)にしない |
| 2枚目 | **手を加えないアプリの画面**。1枚目の答えになる画面 | Stronger は記録や「筋肉にどう効くか」の画面。KATSU ではロック画面に届いた自分の言葉が一番強い |
| 1枚目の型 | 「もし〜だったら」「ひとり言」。知られた言葉(「66日」「モーニングルーティン」「英語」)に乗る | 「もし〜」は続きを見たくさせる。KATSU の考え方はもともとこの形で言える |
| 機能の紹介 | **単独では出さない**(ウィジェット・通知のボタン・アイコン長押しなど) | 設定や機能を見せるだけでは面白くない(Dumbphone を見ての結論) |
| AI の映像 | 使ってよい。ただし下の4つを満たすものだけ | 本人の判断。避けたいのは AI ではなく、中身のない刺激で終わること |
| 声 | 使わない(字幕と音楽だけ) | 顔は出さない。手元は出せる |
| アカウント | 新しく作る。日本語1つから。同じ画像・動画を YouTube Shorts と Instagram リールにも上げる | 週に数時間で回すため。英語は日本語で当たった型が分かってから |
| LP | 作った(`lp/`、§4)。プロフィールのリンクに置けるようになったら貼る | Stronger もプロフィールから1枚の紹介ページに飛ばしている |

### AI の映像を使うときの4つ

1. 基準の1行を通る
2. **静か:** 壊れる・消える・驚かせる映像にしない。炭の色合いで、ゆっくり見せる。「○○が世界から消えたら」の型は使わない(見に来る人が違う)
3. **言葉は人が書く:** 画面の文と、ロック画面に届く言葉は本人が書いたものだけ
4. 「AI 生成」のラベルを付ける

候補: 朝の枕元に「昨日の自分」が静かに立っている / 時計の針だけが進み、部屋の光が朝から夜に変わる / 墨で描いたような1日の時刻表。

## 3. 作り方

素材と仕上がりは**リポジトリの外の `~/katsu-video/`**(リポジトリは公開なので、本人の言葉が写った素材を入れない)。

```
~/katsu-video/
  raw/slides/   2枚目の画面(シミュレーターのスクショ、ストアのスクショの切り抜き)
  cuts/         台本(P01-ja.cut など)
  out/          仕上がり(Pxx-ja/ に 1.png・2.png・mp4)と 投稿メモ.md(説明文・タグ)
```

**2枚目の画面を撮る(シミュレーター):** `bash tools/sim/build.sh` で撮影用の版を入れてから

```sh
xcrun simctl launch <UDID> com.kisshi.gradhabit -katsuDevSeed progress -katsuDevTheme morning -AppleLanguages "(ja)" -AppleLocale ja_JP
xcrun simctl io <UDID> screenshot ~/katsu-video/raw/slides/today.png    # 起動から20秒ほど待つ
```

- 状態・画面・ルーティンの組の名前は `docs/HANDOFF.md`「撮影用の状態と画面」
- ⚠ 入れ直した直後は通知が許可されておらず、Today に「通知がオフなので」の箱が出る。一度アプリの中で「オンにする」→「許可」を押す
- ロックは `osascript -e 'tell application "Simulator" to activate' -e 'tell application "System Events" to keystroke "l" using command down'` で送れる(⚠ 再起動の直後は効かないことがあった)
- 動画の素材は `bash tools/video/record.sh`

**組み立てる:**

```
# ~/katsu-video/cuts/P06-ja.cut
card  3  もし、決めた日の\n自分が\n話しかけてきたら。
image ../raw/slides/lock-zoom.png 3
```

```sh
python3 tools/video/cut.py ~/katsu-video/cuts/P06-ja.cut -o ~/katsu-video/out/P06-ja/P06-ja.mp4 --stills
```

- `--stills` で場面ごとの PNG(写真モードの1枚目・2枚目)も出る
- `card` の文字は1行10字まで(それ以上は語の途中で折り返す)。`\n` で区切る
- 2枚目の文字が小さいときは、画面を切り抜いて大きくする(ロック画面は通知のまわりだけ)
- 1枚目を写真にするときは、写真に TikTok の文字の機能で文を入れる(TikTok でいつも見る字のほうが広告に見えない)
- 音楽は投稿のときに TikTok で付ける(商用利用可の音源、落ち着いた曲)

**スマホから頼む:** Mac の Claude Code で `/remote-control`(Mac は起こしておく)。クラウドの Claude Code では Mac の素材とシミュレーターが使えないので、文面を考えるだけになる。

## 4. LP

`lp/index.html`(日本語)と `lp/en/index.html`(英語)。画像はストアのスクショ(`lp/img/`)。

- **置き場所 【未確定・本人が決める】:** Cloudflare Pages(無料、`<プロジェクト名>.pages.dev`)を勧める。反応が出てきたら独自のドメインを買って付け替える(年に千数百円ほど【未確認】)。github.io は開発者向けの置き場に見える
  - 出し方の例: Cloudflare のダッシュボードで Pages のプロジェクトを作り、このリポジトリをつないで「ビルドの出力先」を `lp` にする。または `npx wrangler pages deploy lp --project-name <名前>`
- **アクセス解析を入れない。**KATSU は「言葉は端末から出ない」を売りにしているので、紹介のページで行動を追わない。数はストアへのボタンにキャンペーンリンク(`ct=`)を付けて ASC で見る(今は普通のストアの URL。ASC でリンクを作ったら差し替える)
- 文面はストアの説明(`docs/asc-listing.md`)と食い違わせない。値段は書かない(変えたときに嘘になる)

## 6. 年始(12月〜1月)

- 「1月1日から」の選択肢は12月の間だけ出る。12月の投稿で「元日を1日目にできる」を2枚目に使う

- ASC 側(本人): App 内イベント「1月1日から、66日」を12月10日ごろ審査に出す / カスタムページ「新年」

## 7. TikTok の決まりで守ること

- [ ] 「66日で必ず身につく」「科学的に証明」と言わない。数字を盛らない
- [ ] 健康の効能を言わない(「眠れるようになる」「痩せる」)
- [ ] 音楽は TikTok の商用利用可の音源だけ 【未確認: 個人アカウントでの扱い】
- [ ] 自分のアプリの宣伝では、投稿設定の「コンテンツの開示」を使う 【未確認: 2026年時点の名前】
- [ ] AI の映像には「AI 生成」のラベル
- [ ] 他人の言葉を紹介するときは、公開で書かれたものを名前を消して
- [ ] 自傷にかかわる内容は出さない・読み上げない。来たら findahelpline.com を短く案内する
- [ ] 「App Store」「iPhone」の名前を正しく書く
- [ ] 地域をごまかす方法(VPN など)は使わない
